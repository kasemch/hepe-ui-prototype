## 2. AI Gap Analysis

### 2.1 Current strengths
1. The course description covers sexuality development, diversity, rights, reproductive health, STI prevention, counseling, and teaching assessment.
2. The course has a clear controlled PLO3/R relationship, suitable for application and reinforcement rather than programme-level mastery.
3. Existing working design already uses case analysis, debate, role play, teaching innovation, micro-teaching, e-portfolio and formative feedback, which is consistent with an R-level learning design.
4. Existing working CLOs span knowledge, applied teaching design, counseling/assessment skill, and self-directed learning.

### 2.2 Gaps to resolve in the next curriculum revision
1. The current controlled curriculum does not yet hold approved course-level CLOs in governed tables.
2. The controlled course mapping only exposes PLO3/R, while parts of the course description and working CLOs strongly concern teaching design and assessment; these should be reviewed against PLO4 in the next curriculum revision rather than silently added now.
3. The self-directed/lifelong-learning dimension in the working CLO4 may warrant review against PLO6, but this is an AI recommendation only.
4. Counseling, sexual rights and non-judgment/boundary practice contain ethical dimensions that should be explicitly represented in learning activities and rubrics, even if no additional PLO mapping is ultimately approved.
5. The course-description-to-CLO-to-assessment chain should be expressed as a single traceable constructive-alignment contract.
6. Assessment evidence should distinguish formative R-level evidence from programme-level mastery evidence; HED2503 should not claim programme mastery solely from course performance.
7. The existing discrepancy between some working documents using 3(2-2-5) and the canonical curriculum value 3(3-0-6) must be formally reconciled during the next curriculum revision.

## 7. Curriculum-Level Recommendations for the Next Revision

### REC-HED2503-01 — Freeze one canonical credit pattern
Retain 3(3-0-6) unless a future curriculum committee formally changes it. Resolve all working 3(2-2-5) variants explicitly.

### REC-HED2503-02 — Add governed course CLO layer
Approve a versioned course CLO set and store it with effective period, authority, source and supersession metadata.

### REC-HED2503-03 — Re-review PLO mapping
Retain PLO3/R as the current baseline. During the next curriculum revision, explicitly consider whether teaching-design/assessment components justify PLO4/R and whether reflective lifelong learning justifies PLO6/R. Do not add either mapping without programme-level review.

### REC-HED2503-04 — Make constructive alignment explicit
For every CLO, require at least one learning activity, one assessment method and one evidence artifact. The system should flag orphan CLO/activity/assessment records.

### REC-HED2503-05 — Strengthen safe and ethical sexuality-education practice
Make inclusion, consent, non-stigmatization, professional boundaries, referral and evidence quality visible in activity and assessment criteria.

### REC-HED2503-06 — Separate R-level evidence from mastery claims
HED2503 at R should provide reinforcement evidence. Programme mastery should be claimed only where the programme has designated M-level evidence and verification.

### REC-HED2503-07 — Add AI provenance guardrails
Future AI suggestions must include: source context used, missing-context warning, proposed/approved distinction, human reviewer identity/status, and no automatic curriculum activation.
